# diabetes-prediction
ML model to predict diabetes

## Project Overview
This project uses Machine Learning to predict diabetes using a medical dataset.

## Technologies Used
- Python
- scikit-learn
- NumPy
- Pandas

## Model
- Logistic Regression

## Results
- Accuracy: 77%
- Precision: 0.68
- Recall: 0.65
- F1-score: 0.67
